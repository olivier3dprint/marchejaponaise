# Marche japonaise — pages publiques

Site de présentation et politique de confidentialité de l'application Android
**Marche japonaise** (« Japanese Walking », `com.marchejaponaise.app`), publiés via
GitHub Pages. Le code de l'application est ailleurs et reste privé.

| Page | URL |

| Confidentialité (FR) | https://olivier3dprint.github.io/marchejaponaise/confidentialite.html |
| Privacy (EN) | https://olivier3dprint.github.io/marchejaponaise/privacy.html |
| app-ads.txt | https://olivier3dprint.github.io/marchejaponaise/app-ads.txt |

La page d'accueil est bilingue (bouton de langue, `?lang=en` pour forcer l'anglais,
sinon langue du navigateur). Les captures de `images/` sont des réductions (540 × 1080,
JPEG) des captures de la fiche Play, faites dans le dépôt privé
(`Play Store/visuels/capture-N_fr|en.png`) : si celles-ci changent, réexportez-les ici.
`partage-fr.jpg` / `partage-en.jpg` (aperçu des liens partagés) sont les images de
présentation 1024 × 500 de la fiche.

`app-ads.txt` déclare l'éditeur AdMob. AdMob ne le lit qu'à la racine du domaine
déclaré comme site du développeur sur la fiche Play ; ici il n'est donc utile que si
ce site-là est déclaré, comme pour les autres applications.

## Activer GitHub Pages

*Settings* › *Pages* › Source : **Deploy from a branch**, branche `main`, dossier
`/ (root)`. La mise en ligne prend une minute environ.

## Tenir la politique à jour

Elle décrit le comportement réel de l'application au 31 octobre 2026 : historique et
réglages stockés sur l'appareil uniquement, aucune localisation, aucune donnée de
mouvement lue (l'autorisation « Activité physique » n'est demandée que parce qu'Android
l'exige pour un service au premier plan de type santé), et un seul échange avec un
tiers : la publicité AdMob.

Elle devra être révisée si l'application gagne un outil de mesure d'audience ou de
remontée de plantages, un compte utilisateur, des achats intégrés, la lecture de
capteurs (podomètre) ou une synchronisation (Health Connect…).

Les réponses du formulaire *Sécurité des données* de la Play Console doivent rester
cohérentes avec ces pages : modifier l'un impose de vérifier l'autre.
